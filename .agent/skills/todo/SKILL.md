# Todo Skill 지침

이 스킬은 프로젝트의 "todo.md" 파일 내용을 불러와 사용자에게 할 일 목록 및 다음 진행 단계를 상기시켜 줍니다.

## 실행 절차

1.  **todo.md 읽기**: 루트 디렉토리에 위치한 `todo.md` 파일을 읽어들입니다. `view_file` 도구를 사용하세요. (절대경로: `/Users/sj/Project/FluxX/todo.md`)
2.  **현재 상태 파악**: 
    - 파일을 읽은 뒤, 완료된 체크박스(`[x]`)와 아직 진행하지 않은 체크박스(`[ ]`)를 파악합니다.
3.  **결과 안내**:
    - 파일 내용을 바탕으로 아직 완료하지 않은 핵심 작업들을 요약하여 사용자에게 보여줍니다.
    - 사용자가 이어서 진행할 항목이 무엇인지 묻고, 바로 다음 스텝에 착수할 수 있도록 돕습니다.

## 주의 사항
- `todo.md` 파일이 존재하지 않는 경우, 사용자에게 해당 파일이 없다고 안내하고 새롭게 생성할지 물어봅니다.
